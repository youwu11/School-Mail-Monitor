检查邮件正文、附件、PDF 和来源链接。

根据 Outlook 或 Gmail 邮件中的实际内容，识别孩子所在学校及其使用的学校网站、家校沟通平台或通知门户，并设置云端浏览器的访问权限。

1. 从相关邮件中提取实际使用的网站链接，打开有代表性的通知或页面进行测试，不预设学校或平台名称。

3. 在设置支持的情况下，引导我将相关网站的云端浏览器权限设为“始终允许”（Always Allow）。
4. 验证能否读取链接中的通知和 PDF。
5. 报告所有无法访问的来源。

不要提交表单或修改任何信息。

手动操作MANUAL SETUP STEPS

📋 提示词📋 PROMPT
阶段 1 — 创建存储文件

在当前工作空间的文件库中，为孩子邮件监控和每日提醒设置持久存储。

创建：
1. kids_email_state.json — 保存邮件检查进度、去重记录、待提醒事项和待办事项。
2. manual_reminders.json — 保存用户手动提供的提醒，包括活动、截止日期、准备事项和后续跟进。

采用精简的 JSON 结构，包含稳定的唯一标识、来源引用、状态、时间戳，以及适用的重试信息。

将运行状态与任务配置分开保存。

只有获得用户明确授权，才可根据自然语言指令，在 manual_reminders.json 中新增、更新、标记完成或取消提醒。定时运行时，不得修改该文件。

报告文件路径、数据结构摘要，以及任何不支持的功能。
02创建邮件监控任务Kids Email Monitor⌄

手动操作MANUAL SETUP STEPS

📋 提示词📋 PROMPT
阶段 2 — 创建孩子邮件监控任务

创建一个名为 Kids Email Monitor 的定时任务，使用 Australia/Sydney 时区，每小时运行一次。

初始设置：
创建前，确认孩子的姓名、常用称呼、学校、班级、出勤日及课外活动。将家庭配置与运行状态分开保存。

目标：
监控已连接的 Outlook 或 Gmail 中新增或更新的孩子相关邮件，包括学校、托育、课外活动、生日聚会、玩伴聚会和医疗预约。忽略营销邮件。

处理与存储：
读取可访问的邮件、附件及链接中的通知，在支持的情况下使用云端浏览器。将有意义的孩子相关动态、活动、准备事项和待办事项提取并保存到 kids_email_state.json。保留来源链接及更新信息。提醒发送由独立任务负责。

汇报：
像一位为忙碌妈妈提供帮助的贴心私人助理，用自然、简洁的简体中文，总结每个孩子在学校生活、学习、活动、成长进展及身心状况方面的重要动态。突出关键日期、待办和准备事项，附上来源链接，及时提醒紧急变化，避免猜测、琐碎信息和重复通知。

可靠性：
每次从上次成功检查的时间点往前回溯 2 小时，结合稳定的唯一标识和内容变化检测，去重并处理更新。保存检查进度，对处理失败的内容进行重试，不丢失有效记录。只有确认数据已持久保存后，才推进检查进度。记录保持精简，不保存完整邮件正文。验证文件访问能力，并报告访问失败或尚未验证的跨运行持久存储能力。

安全：
运行数据只写入 kids_email_state.json。不得修改其他任务或本任务说明，也不得将运行历史写入任务提示词。

设置与验证：
确认所需访问权限；仅在状态文件不存在且可以写入时初始化文件，然后只创建 Kids Email Monitor。核实其每小时运行的悉尼时区设置、完整任务说明及文件持久存储能力，并报告不支持的功能。
03创建每日提醒任务Kids Daily Reminder⌄

手动操作MANUAL SETUP STEPS

📋 提示词📋 PROMPT
阶段 3 — 创建每日提醒任务

创建一个名为 Kids Daily Reminder 的定时任务，使用 Australia/Sydney 时区，每天 18:00 运行。

目标：
像一位为忙碌妈妈主动提供帮助的私人助理，每晚用自然、简洁的简体中文，汇报未来 10 天与孩子相关的活动和事项。

信息来源：
读取 kids_email_state.json 和 manual_reminders.json。在支持的情况下，使用已登录的云端浏览器查看链接中的通知。允许根据用户明确授权的自然语言指令，更新 manual_reminders.json。

汇报：
按时间顺序总结即将到来的学校活动，包含日期、时间、地点、准备事项及重要备注。省略已完成的待办事项和重复内容。有来源链接时附上链接。

可靠性：
对活动去重，以最新的更新和取消信息为准，验证文件的持久存储能力。遇到访问失败时如实报告，不要猜测。

安全：
定时运行时只读取信息，不修改文件。只有用户明确要求时，才可修改 manual_reminders.json。

核实任务是否创建成功、运行时间及文件访问能力，并报告不支持的功能。
04历史邮件补录与激活Historical Backfill & Activation⌄

手动操作MANUAL SETUP STEPS

📋 提示词📋 PROMPT
阶段 4 — 历史邮件补录与激活

通过已连接的 Outlook 或 Gmail，检查过去 20 天与孩子相关的邮件，包括可访问的附件和链接中的通知。

1. 提取即将到来的活动、提醒、截止日期和待办事项。
2. 将相关动态和提醒自动更新到 kids_email_state.json，避免重复，不进行不必要的确认。不创建日历队列，也不同步日历事件。
3. 验证提取内容的准确性、文件持久存储能力及提醒功能。报告任何失败。
4. 确保 Kids Email Monitor 和 Kids Daily Reminder 已启用，并能访问更新后的文件。

安全：
不要编造缺失信息、发送邮件、修改日历或创建重复任务。仅在确有必要时请求授权。
